Image Infill

Image Infill Boundary Propagate
Fills the target region by propagating colors inward from the target boundary using a random-weighted onion-peel rule (simple content fill for inpainting prep).
Image Infill Exemplar Region Fill
Image Infill using exemplar region filling with isophote-driven priority. extends linear structures into the target region.
Image Infill Gaussian Mixture Layer
Single stationary-Gaussian-field texture inpainting by FFT-based conditional simulation (Galerne-Leclaire 2017); best for homogeneous microtextures. (Name retains historical "Mixture" for compat; not a GMM.)
Image Infill PatchMatch
Approximate PatchMatch-style content fill to infill masked regions; useful as inpainting guidance.
